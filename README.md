# 分析工坊 · 数据分析与数据应用平台

面向指标口径管理、多维度聚合查询、用户分群圈选、AB实验评估、时序趋势分析与数据服务发布的数据分析与数据应用平台。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/              统一请求封装
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/          每个业务模块一组接口
│   ├── app/services/         业务规则与状态流转
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm ci
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 约定

- 每个模块的前端页面在 `frontend/src/views/<模块>/index.vue`，后端接口在
  `backend/app/routers/<模块>.py`，业务规则在 `backend/app/services/<模块>.py`。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。

## 跨源日报包（cross_source_daily）

把预测、分群、实验三个来源按**业务截止日**合并成一份带版本的跨源日报包，
接口在 `/api/cross_source_daily/packages`，前端从「报表生成 → 跨源日报包」进入。

- 每个章节只选取该来源**一份已完成的完整产物**，并保留 `业务截止日`、`实际业务日`
  与 `来源版本`；预测/分群读各自的完成产物，实验读数据集市的完成统计快照
  （输入产物见 `backend/app/fixtures.py` 的 `FORECAST_ARTIFACTS`、
  `COHORT_ARTIFACTS`、`EXPERIMENT_SNAPSHOTS`）。
- 实验统计可能迟到：选不到业务截止日当天的快照时，回退到最近一个已完成快照，
  章节标记 `统计迟到`，读者可直接看到该章实际使用的日期与版本。
- 只有**统计周期可比**（如同为日粒度）且当天各章都有值的指标，才会进入
  `同日对照.comparable`；周粒度或仅单章有值的指标进入 `non_comparable` 并附原因。
- 实验章节的转化变化（对照组/实验组转化率、绝对/相对变化、z 检验）完全由数据集市
  快照里的分组计数计算。
- 每次出包生成新版本并关联到同一份 `report_gen` 报表，新旧版本共存，可分别打开核对。
  出包时可用 `experiment_max_cutoff` 模拟实验快照迟到的场景。
